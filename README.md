# SpendWise - Smart Budget Tracker

## What your SpendWise project does
SpendWise helps users track income and expenses...

## The JavaScript concepts implemented
- Variables, Data Types, User Input via prompt(), Functions, Calculations, Conditionals, DOM, Events, Console

## How variables are being used
- let for mutable budget data, const for APP_NAME and CURRENCY

## How user input is collected
Using Number(prompt()) with validation

## How calculations are performed
Total = rent+food+transport+entertainment, Remaining = income-expenses, Savings% = (balance/income)*100

## How functions help organize the code
Reusable functions like calculateTotalExpenses(), calculateRemainingBalance() follow DRY principle
